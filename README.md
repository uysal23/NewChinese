# NewChinese

Simplified Chinese (简体中文) learning Android application for HSK1–HSK6.

This repository is governed by the locked project manifests in the repository root. Development must read and preserve those rules before changing product behavior, content, visuals, audio, study flow, validation, or build logic.

## Locked planning status

- Steps 01–20: LOCKED
- Target content: 6 HSK levels × 50 scenes = 300 scenes
- Android: Kotlin + Jetpack Compose
- Architecture: MVVM, Room, DataStore, Media3, local-first content
- Build: GitHub Actions, APK + future AAB/release readiness

## First implementation milestone

1. Repository/project skeleton
2. Root locked manifests
3. Core Android app shell
4. HSK1 SC001 as the end-to-end reference scene
5. Validation/build workflow

See `LOCKS.md` before making changes.
